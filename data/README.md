# Data

- `consonant-samples.json`: recorded consonants (noises of s, ʃ, f, x and ch; bursts of p, t and k) for the female
  (`f`) and male (`m`) voice. Format: `{ fs, sets: { f|m: { consonant: { mode: "loop"|"shot", tok: [{ v, k, d }] } } } }`,
  where `v` is the vowel that followed in the recording, `d` the 16-bit PCM at `fs` Hz in base64 and `k` the scale factor.
  The page downloads it when the audio is turned on (`js/voice/audio-engine.js`) and `js/voice/consonant-samples.js` decodes it.
  It is generated by `tools/measure-dataset/extract.py`.

  These are fragments of OpenSLR 61, *Crowdsourced high-quality Argentinian Spanish speech data set*
  (A. Guevara-Rukoz et al., «Crowdsourced Latin American Spanish for Low-Resource Text-to-Speech», Proc. LREC 2020),
  licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). These fragments are shared under the same license.

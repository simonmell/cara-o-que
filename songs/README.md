# Songs

Each subfolder is a song: an UltraStar `.txt` (lyrics, notes and timing) and, optionally, its backing track
(`.mp3`, `.ogg`, `.m4a`...). The folder name is the name shown in the song list.

Only these public-domain songs are part of the repository:

- `Los pollitos dicen/`: traditional children's song, without music (sung with the melody guide).
- `Twinkle, Twinkle, Little Star/`: English demo (lyrics by Jane Taylor, 1806; traditional melody).
- `Himno Nacional Argentino - Blas Parera/`: Argentine National Anthem (lyrics by Vicente López y Planes, music by
  Blas Parera).

Any other folder you add here, and every audio file, is ignored by git (see `.gitignore`), so commercial songs and
karaoke tracks stay on your computer.
